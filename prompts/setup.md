# Set up law-brain for me

I'm a law student and I've never used a terminal. Explain things in plain English, and
tell me before you do anything I might not expect.

1. **Get the kit.** If the folder you're in already has a file named `AGENTS.md`, the
   kit is already here: skip to step 2. Otherwise download
   https://github.com/nikhildhoka8/law-brain/archive/refs/heads/main.zip into this
   folder, unzip it, and rename the unzipped folder to `law-brain`. Use only tools
   already on my computer (`curl`, then `unzip` or `tar`). Don't install anything. I
   don't have a GitHub account and don't need one. If a `law-brain` folder already
   exists here, stop and ask me what to do.
2. **Read the rules.** Read `AGENTS.md` in the kit folder and follow it from here on.
3. **Find my materials.** Ask me where my class materials are: a folder on my
   computer (like my Desktop or Downloads), Google Drive, OneDrive, Notion, Canvas,
   email, or somewhere else. Then follow AGENTS.md section 8: find the files, show me
   the list, and wait for my OK.
4. **Copy and sort.** Copy (don't move) each file into the right `raw/` subfolder:
   `syllabus`, `cases`, `class-notes`, `outlines`, or `exams`. Ask me about any file
   you aren't sure about. Skip anything that isn't class material, and tell me what you
   skipped.
5. **Build my brain.** Follow `prompts/ingest.md`.
6. **Show me how to use it.** Finish with short, numbered steps for:
   - opening my vault in Obsidian and finding my course map and the graph view;
   - opening you in the `law-brain` folder next time, so after each class I can drop
     new notes into `raw/` and just type `/ingest` (or "run the ingest prompt").
