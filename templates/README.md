# templates/

One blank template per note type. Your agent copies these when it creates a note, so
every note has the same fields and headings. The rules for each field and heading are in
`AGENTS.md` (sections 1 and 2). You don't need to edit these.

| Template | Used for |
|---|---|
| `case.md` | A case you read |
| `rule.md` | A legal rule or test |
| `topic.md` | A course topic (a unit on the syllabus) |
| `hypo.md` | A hypothetical from class, the casebook, or an exam |
| `professor.md` | Something your professor said that matters for the exam |
| `source.md` | A record of each file the agent ingested |
