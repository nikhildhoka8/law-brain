# class-notes/

**Put here:** your own notes from each class. Start the file name with the date so the
agent can order them: `2026-09-14-proximate-cause.md`. Messy is fine. Write down
anything your professor emphasized; the agent looks for those signals.

**Do not put here:** another student's notes unless they gave you permission, or
recordings and transcripts your school does not allow you to share.
